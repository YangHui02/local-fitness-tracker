# 日常热量摄入与消耗记录

这是一个只在本机运行的健身与饮食月度记录网站。数据保存在当前浏览器的本地存储中，不需要数据库，也不会上传到网络。

## 启动

1. 双击 `start.bat`。
2. 浏览器会自动打开 `http://127.0.0.1:8765/`。
3. 使用网站期间请保持命令窗口打开。
4. 用完后关闭命令窗口，或在窗口中按 `Ctrl+C`。

如果端口 8765 已被其他程序占用，关闭占用该端口的程序后重新双击启动。

## 每日记录

1. 选择日期。
2. 填写体重；支持按 `0.05 kg` 录入并最多显示两位小数。体重可留空，留空不会被当成 0 kg。
3. 选择训练日或休息日。
4. 按“碳水、蛋白质、脂肪”顺序填写实际摄入。
5. 填写步数、力量训练时长和有氧消耗。
6. 点击“保存当日记录”。

当日热量按以下公式自动计算，不能手工修改：

```text
碳水 × 4 + 蛋白质 × 4 + 脂肪 × 9
```

热量盈余按“当日热量 − 当日总消耗”计算。正数是盈余，负数是缺口。

## 修改计划

点击页面右上角的“计划与参数”，可分别修改：

- 训练日的碳水、蛋白质、脂肪；
- 休息日的碳水、蛋白质、脂肪；
- 默认体重、基础代谢、活动系数、步数系数和力量训练 MET。

计划热量也按 4/4/9 公式自动计算。新设置只用于之后保存的新记录；已经保存日期中的计划快照不会跟着改变。

## 查看和修改

- 顶部“月度 / 年度”按钮用于切换汇总范围。
- 顶部月份控件可以切换月份，历史月份彼此独立。
- 在“当日录入”中选择已有记录的日期，会自动载入该日全部数据；修改后保存会覆盖该日期的原记录，不会新增重复记录。
- 选择尚无记录的日期时，其他输入会恢复为新增记录的默认状态。
- 保存后表单会保留刚保存的完整数据并进入编辑状态，可直接继续修改和覆盖，无需切换日期。
- “本月记录”表格中的“编辑”用于重新填写某一天。
- “删除”只删除选中的日期，操作前会再次确认。
- 页面下方展示体重、摄入与消耗、三大营养元素实际克数和热量盈余。

## 年度汇总

切换到“年度”后，可以选择年份并查看：

- 全年的记录天数、日均摄入、日均消耗、累计盈余和体重变化；
- 每个有记录月份的记录天数、月平均体重、日均摄入与消耗、累计盈余；
- 每月日均碳水、蛋白质和脂肪；
- 按月汇总的摄入、消耗、盈余和三大营养元素日均实际克数。

年度表格不会为没有记录的月份补零。点击表格中的某个月份，会自动切换到该月的每日明细。

体重图始终位于可视化区域第一行：

- 月度模式按实际填写日期显示体重；
- 年度模式默认显示每个月的平均体重；
- 年度模式可切换为“按天记录”，查看全年每次实际填写的体重；
- 未填写体重的日期不会被当成 0 kg。

四张图表均独占整行，顺序为：

1. 体重趋势；
2. 热量摄入与消耗；
3. 热量盈余；
4. 三大营养元素实际摄入。

三大营养元素图不显示计划达成率：月度模式显示每日实际碳水、蛋白质和脂肪克数，年度模式显示每个月的日均实际克数。

月度和年度图表使用相同的固定纵轴规则：体重每 `0.5 kg` 一条辅助线；热量摄入与消耗每 `200 kcal` 一条；三大营养元素从 `20 g` 开始每 `80 g` 一条；每日热量盈余每 `50 kcal` 一条并始终包含 `0`。各图上下限会根据当前显示的全部数据自动向外扩展。

把鼠标移到任意折线点或热量盈余柱上，会立即显示该日期（年度按月汇总时为该月份）的具体数值。多条折线会在同一个提示框中合并显示，数值分别使用 `kg`、`kcal` 或 `g`，热量盈余保留正负号。

年度汇总由已有每日记录即时计算，不会修改原记录。本次功能未改变本地存储键或记录结构，现有数据和 JSON 备份继续兼容。

## 备份与恢复

- 点击“导出备份”会下载一个 JSON 文件。
- 点击“导入备份”可选择之前导出的 JSON 文件。
- 导入会替换当前浏览器中的全部记录和设置，网站会先要求确认。

建议每周或每月导出一次备份。请只导入自己导出的可信文件。

## 数据保存范围

数据属于当前电脑、当前浏览器、当前浏览器用户配置。以下操作可能使未备份的数据丢失：

- 清理 `127.0.0.1:8765` 的网站数据；
- 重置或卸载浏览器；
- 更换电脑或浏览器用户配置。

导出的 JSON 备份可以用于恢复数据。
